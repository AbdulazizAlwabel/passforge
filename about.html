Trust & Transparency

Why trust PassForge?

Short answer: don't trust us — verify it yourself. Every tool below is built so you can check exactly what leaves your browser, in under 10 seconds.

1

How the tools work

Every generator, checker, and converter on this site — the password generator, hash generator, strength checker, Base64 tool, and the rest — runs entirely in JavaScript inside your browser. Nothing you type, generate, or paste into these tools is ever sent anywhere. There's no server-side processing to send it to.

Verify this yourself, right now

  • 1Open any tool page, e.g. the Password Generator.
  • 2Press F12 (or right-click → Inspect) and open the Network tab.
  • 3Clear the log, then click "Generate Password" a few times.
  • 4Watch the Network tab. You'll see zero new requests fire — no fetch, no XHR, nothing leaving the page.
2

What actually talks to a server — and why

To be precise (vague privacy claims are how bad actors get away with lying): the tools are 100% local. The optional account system — sign in, sign up, saved profile — does talk to our server, because that's the only way an account can exist. Here's the exact breakdown:

FeatureSends data to a server?
Password Generator● Local only
Strength Checker● Local only
Hash Generator● Local only
Base64 / JSON / Text / Unit / Date tools● Local only
Sign in / Sign up / Profile● Server (only if you create an account)

You never need an account to use any tool. Signing up only exists for people who want saved history across devices — it's optional, not required.

Connection security

This entire site is served over HTTPS, including every tool page, the API, and all assets. Your browser's padlock icon confirms the connection itself is encrypted — check for it in your address bar right now.

Who built this

A

Built by a solo developer, not a company.

PassForge started as a personal itch: most "free online tools" sites are ad-stuffed and vague about what they do with your input. I wanted a password generator I'd actually trust for my own accounts — so I built one, made the logic auditable, and put it up for anyone else who wants the same thing. No VC funding, no data resale, no dark patterns. Just tools that do the one thing they say they do.
