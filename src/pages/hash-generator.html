Which hash?

  • SHA-256 is the default choice for checksums and integrity checks.
  • MD5 and SHA-1 are broken for security — fine only for non-adversarial checksums.
  • Never store passwords with plain hashes; use bcrypt, scrypt or Argon2.

About hashing

A cryptographic hash turns any input into a fixed-length fingerprint. Change a single bit of input and the output changes completely. That makes hashes ideal for verifying downloads: compare the checksum a vendor publishes with the one computed here.

SHA digests are computed with your browser’s native Web Crypto API; MD5 uses a small built-in implementation, since browsers deliberately don’t ship it.
