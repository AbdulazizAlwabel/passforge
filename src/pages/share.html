Links you created

Only the status is stored — never the secret or its key. Anonymous links are remembered in this browser only.

How it works

  • Your secret is locked on your device before it’s sent. The key to open it is only in the link — I never see it.
  • The first time someone opens the link, the secret is deleted for good.
  • Add a password for extra safety: five wrong tries and it destroys itself.

Safe with link previews

WhatsApp and other apps that preview links can’t use up your secret — the person has to tap Reveal.

Stop pasting passwords into chats

Messages stay in chat histories, emails and backups for years. A one-time link keeps your secret out of all of them: once the other person opens it, the copy on my server is erased and the link stops working.

Can you read my secrets?

No. The secret is locked on your device, and the key lives only in the part of the link after the #, which browsers never send to any server. I only ever store scrambled data.

What if someone else opens the link first?

They’d see the secret — but then the person you meant it for would see “already viewed”, so you’d know. For important secrets, add a password and send it a different way (for example, say it on a call).

What happens when it expires?

The locked secret is deleted within minutes, and the record of the link is removed after 30 days.

For the technical folks

AES-256-GCM with a fresh random key in the URL fragment; an optional password adds PBKDF2 with 600,000 rounds. The code is open source — see assets/secret.js.
