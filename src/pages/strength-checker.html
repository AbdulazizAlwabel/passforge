How we estimate

  • Entropy starts from length × character pool, then is penalised for dictionary words, sequences, repeats, keyboard walks and dates.
  • Crack times assume an attacker guessing at the rates shown, finding it halfway through on average.

What makes a password weak?

Attackers don’t guess randomly. They start with leaked password lists, then try dictionary words with common substitutions (p@ssw0rd), keyboard patterns (qwerty), years and dates, and short repeated chunks. A password can look complex and still fall in seconds if it follows one of these patterns.

The fix is randomness and length. Use a password manager and let the Password Generator create something no human would choose.
