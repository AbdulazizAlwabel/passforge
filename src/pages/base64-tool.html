Good to know

  • Base64 is an encoding, not encryption — anyone can decode it.
  • Encoded output is ~33% larger than the input.
  • URL-safe mode swaps + / for - _ and drops padding, as used in JWTs.
  • Decoding auto-detects URL-safe input and missing padding.

What is Base64 used for?

Base64 represents binary data using 64 printable characters, so it can travel safely through systems built for text — email attachments, data URLs in CSS and HTML, HTTP Basic auth headers, JSON Web Tokens and configuration files.

This tool handles full Unicode (emoji and Arabic included) by encoding to UTF-8 bytes first, which the browser’s built-in btoa can’t do on its own.
